# Tool catalog

DO NOT EDIT — generated by `python -m omega_prime.tooling.catalog`.
Rebuild with `--out docs/tool-catalog.md`; CI fails when this file drifts.

## read_file

- Family: Coding
- Approval: not required
- Required params: path

Read a UTF-8 text file inside the workspace root. A path that escapes the root is an error. Returns the file contents.

## write_file

- Family: Coding
- Approval: not required
- Required params: path, content

Write a UTF-8 text file inside the workspace root, replacing any existing content. Parent directories are created. A path that escapes the root is an error and writes nothing.

## patch_file

- Family: Coding
- Approval: not required
- Required params: path, diff

Apply one unified diff to one file inside the workspace root. If a hunk's context does not match, the file is left byte-for-byte unchanged.

## edit_file

- Family: Coding
- Approval: not required
- Required params: path, diff

Apply one unified diff to one file inside the workspace root, repairing hunks the exact apply cannot place by re-anchoring unique context or matching whitespace-insensitively. If no repair places every hunk, the file is left byte-for-byte unchanged.

## search_text

- Family: Coding
- Approval: not required
- Required params: query

Find a literal string under the workspace root and return the matching relative paths. The query is not a regular expression. Paths outside the root are not searched or returned.

## run_terminal

- Family: Coding
- Approval: not required
- Required params: argv

Run a program from an argv list with its working directory inside the workspace root. This is not a shell: the command string is not parsed or expanded. stdout, stderr, and the exit code are captured. A timeout stops the process. A working directory outside the root is refused.

## todo_write

## omega_command

- Family: Omega command
- Approval: not required
- Required params: command

Run one Omega Prime slash command. Pass the user's /omega-... text exactly. Use this instead of the underlying tools when the user typed a slash command or asked for onboard, connectors, a Python check, desk status, doctor, roster, recall, retain, gates, or delegate. Generated commands run here too: /omega-<skill> loads that skill's instructions, and /omega-<routine> runs that routine's workflow or loads its instructions. A generated name that matches a curated command or another generated name takes a -skill or -routine suffix (/omega-python-skill loads the python skill; /omega-python runs the check). /omega-help lists every command.
