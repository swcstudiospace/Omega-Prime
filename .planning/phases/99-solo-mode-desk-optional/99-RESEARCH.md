## Current facts (source observations)

- **Composition/identity seam:** `omega_prime/mcp_server.py:760-768` shows `default_registry(root, home, *, policy, approval_log, env, work_root)` accepts no bot/seat identity. It constructs lead stores, shared `SubstrateClient`, and `LeadContext` at `:887-937`; it separately constructs a docs-only `SubstrateClient` from `OMEGA_PRIME_DESK_DOCS_INDEX` (`:897-924`) and notifier from `OMEGA_PRIME_DESK_NOTIFY_URL` (`:925`). The bus constructor uses ready binding, env URL, or literal `http://127.0.0.1` (`:900-935`). `LeadContext.bot_id` currently defaults to `bot-00-omega-prime` (`tools/lead.py:541-558`).
- `load_runtime` has roster visibility: it parses the install tool roster at `mcp_server.py:1391-1420`, then invokes `default_registry` at `:1438-1445` without passing any seat identity. This is the existing natural composition seam for explicit seat identity, but how a no-roster direct `default_registry` call identifies its seat must be decided before editing; treating the default `LeadContext.bot_id` as universal would silently alter other-seat defaults. Inventory all `default_registry`, `load_runtime`, and `LeadContext` callsites/constructions before the optional API change.
- **Current lead routes:** `tools/lead.py:600-626` validates model-facing `query`, calls injected `docs_index`, and returns bounded/redacted fields. Event emission appends to local EventStore and calls `ctx.substrate.emit`; failure is surfaced with `local_mirror:true` (`:886-925`). The doctor `check` is read-only and aggregates prompt, skills, memory, tools, roster, and substrate-object-presence checks (`:927-1004`); current substrate green means only that an adapter object exists, not that the route is reachable. Bus start checks only whether an injected bus exists (`:1165-1198`); bus wait uses the same injected seam (inventory source: `:786-839`).
- **Substrate and docs shaping:** `substrate/client.py:189-193` currently maps `docs_search(query)` to MCP `tools/call` arguments `{"query": query}`. This conflicts with the explicit Phase 97 target `question`; `tests/test_substrate.py:218-232` asserts the existing query envelope. `tools/substrate_tools.py:78-113,116-196` distinguishes valid `chunks: []` from malformed containers, errors, and unreachable substrate, and shapes bounded/redacted provenance. The lead adapter should reuse this existing client/shaper, not establish another docs path. Preserve `lead_docs_search` public/model-facing `query` unless an intentionally scoped public API change is required; only transport mapping to `question` is required by the supplied prerequisite.
- **Saved binding semantics:** `integrations/gateways.py:189-204,207-273` documents/implements saved ready URL precedence and refusal for skipped/invalid/degraded rows. Missing/unconfigured entries allow the supplied fallback; status can distinguish not configured. Solo must suppress Desk routes regardless of configured env or saved binding, while Desk mode may use only explicit permitted routes. No missing/blocked binding should synthesize an endpoint.
- **Local state and children:** `mcp_server.py:823-852,904-916` wires shared local `MemoryStore`, intake, roster, and event stores; all are independent of Desk network configuration. Child model/parent construction is separate (`:853-870`), and `LeadContext` is injected with the shared substrate and local stores. Preserve this local/child behavior; no memory cutover or deletion of Desk code is in Phase 99.
- **Routine behavior:** `routines/desk_lead.py:60-166,217-330,466-503` implements real parent child dispatch, explicit blocked outcomes/failure receipts, reopening blocked intake, and honest no-dispatcher behavior. Keep DeskDriver and local routine behavior; do not use the bus as a substitute for child execution or expand into an engine/command aggregation rewrite. Existing tests include no dispatcher / blocked / child-success paths (`tests/test_desk_lead.py:46-175`).
- **Useful deterministic test seams:** `tests/test_substrate.py:20-82` has a scripted transport that records exact HTTP/MCP request bodies, including current docs argument assertion at `:218-232`; `tests/test_lead.py:56-108,425-479` supplies context, fake substrate/bus, local event/error, and docs result patterns. `tests/test_desk_wiring.py:53-121` exercises production `default_registry` and local stores. These should be extended to dispatch real registry tools with faked production transports; fake lead adapters alone cannot prove selected host or wire envelope.
