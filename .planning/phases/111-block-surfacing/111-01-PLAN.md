<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Engine/hook failure text → tasks.json row | Rows leave the process for the dashboard and Ove; ask/blocks are the only free text that crosses. |
| Concurrent writers (box digest routine, engine, push hook) | One tasks.json, multiple writers on the same host; interleaved or partial writes corrupt the operator's view. |
| Any code with the path → waiting_on_ove | The helper is a public API; a caller can raise or clear items for any task id. |
| Engine failure path → visibility write | The block write runs inside the engine's failure handler; it must never become a second failure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-111-01 | Information disclosure | ask/blocks/detail free text in tasks.json | high | mitigate | redact_text on every stored string (W111-03); reason codes + static text instead of argv/exception detail; test reads raw file bytes for the secret-shaped inputs (W111-03). |
| T-111-02 | Tampering | tasks.json write path | medium | mitigate | Sidecar flock for the whole read-modify-write + atomic same-directory os.replace; no partial JSON observable; unknown fields pass through so the dashboard's own fields survive (W111-01). |
| T-111-03 | Spoofing | waiting_on_ove item duplication | medium | mitigate | Stable deterministic ids + upsert; seq allocated once; a retrying caller can never forge a second item or reset a block's age (W111-02). |
| T-111-04 | Denial of service | block write inside the engine failure handler | medium | mitigate | contextlib.suppress around raise_block; stdlib-only, one short locked section; an engine failure always returns its EngineResult even if visibility writing fails (W111-04). |
| T-111-05 | Tampering / repudiation | clear_block state flip | low | mitigate | Clear flips only blocked → working; terminal done/failed rows are never resurrected; since/seq preserve the operator's audit order (W111-02). |
| T-111-SC | Supply chain | new omega_prime/dashboard package | high | mitigate | Stdlib only (json, fcntl, os, datetime, contextlib, pathlib, typing, tempfile); reuses the existing credentials redactor; no new dependency, no package legitimacy checkpoint auto-approved. |
