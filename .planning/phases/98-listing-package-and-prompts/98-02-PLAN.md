<objective>
Create the install prompt, the five follow-up prompts and their index, and the test file that enforces the whole listing package. The test file covers plan 98-01's files as well, so this plan is the gate for the phase.

Purpose: the operator pastes one install prompt into the default Grok Bot and then sends one `/omega-*` command at a time. Each prompt must send a command that exists in the repository, and each prompt must say what it does not prove. A drift between the install prompt and SETUP.md must fail a test, not reach a Bot.

Output: five prompt files, one index, one install prompt, and `omega_prime/tests/test_grokbot_listing.py`.

Locked by the user: the install prompt is copied verbatim from SETUP.md section 1 by a script or a test, not retyped; the follow-up set is the five prompts named in 98-CONTEXT.md; the root `LICENSE` stays unchanged; live Grok Bot import stays UNPROVEN in every file; no emojis; plain markdown; do not commit planning docs.

Phase success criteria (verbatim from ROADMAP.md phase 98):
1. `omega_prime/grokbot/listing/README.md` links to the install prompt and the follow-up prompts rather than duplicating them, and each claim it makes cites its source file and evidence level
2. `omega_prime/grokbot/listing/prompts/install.md` matches the install task block in `omega_prime/grokbot/SETUP.md` section 1 verbatim, and its stdio command equals the one declared in `mcp.json`; drift fails a test
3. Each of the five follow-up prompts in `prompts/follow-up/` names the exact `/omega-*` command it sends and states what it does not prove; a prompt naming a command with no file in `omega_prime/grokbot/plugin/commands/`, or a prompt missing from the index, fails a test
4. The listing `CHANGELOG.md` has a v20 entry, and the listing `LICENSE.md` names AGPL-3.0-only and points to the unchanged root `LICENSE`

Requirements: INS-01, INS-02, INS-03. The test file also enforces LST-01, LST-02 and LST-03 from plan 98-01.
