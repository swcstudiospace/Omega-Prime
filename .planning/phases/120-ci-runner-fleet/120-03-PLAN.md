<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Controller → agent ASGI | Untrusted network requests carrying one-time JIT reservation; bearer secret and chunked body cross boundary. |
| Agent → runner child | Privilege boundary for untrusted job code; child receives JIT input and may emit hostile output. |
| Agent → callback controller | Authenticated one-shot exit notification; must not expose runner secrets or accept stale identity as another runner. |
| Build inputs → Railway Desktop image | Upstream image, desktop source/entrypoint, and runner tarball supply-chain trust boundary. |
| Desktop process → Railway ingress/runtime | Public health/agent route and separate existing desktop service route; serverless lifecycle is externally managed. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-120-21 | Spoofing | Agent API | high | mitigate | Constant-time bearer comparison; auth on every sensitive route; health reveals no secrets. |
| T-120-22 | Tampering | Request parser | high | mitigate | Streamed 1 MiB cap, strict JSON shape, validated path/name, generation conflict rejection. |
| T-120-23 | Denial of service | Capacity and process spawn | high | mitigate | Atomically reserve against independent cap before async spawn; reject full capacity with 429; bounded bodies and teardown. |
| T-120-24 | Information disclosure | JIT config and child environment | critical | mitigate | JIT only in `ACTIONS_RUNNER_INPUT_JITCONFIG`; no disk, argv, response, repr, logs, events; scrub secrets from env. |
| T-120-25 | Tampering | Child output and event/log publishing | high | mitigate | Redact using known-secret extras on every emission; discard output that cannot be safely redacted. |
| T-120-26 | Denial of service | Process lifecycle | high | mitigate | Process-group graceful termination plus bounded escalation, wait-based completion, single cleanup and capacity release. |
| T-120-27 | Elevation of privilege | Runner child | critical | mitigate | Dedicated non-root job UID/GID distinct from agent credential owner; token files and agent environment unreadable to jobs; private mutable work roots and shared read-only runner installation. Nice, rlimits, and workdir isolation alone are not confidentiality boundaries. No Docker privilege/DinD claim. |
| T-120-28 | Tampering | Desktop image supply chain | critical | mitigate | Immutable verified upstream image/source and entrypoint digest; published runner tarball checksum; fail closed on missing evidence. |
| T-120-29 | Denial of service | Callback and idle service | medium | mitigate | One-shot finite injected callback only after cleanup; no retry daemon or periodic outgoing traffic; serverless sleep retained. |
| T-120-SC | Tampering | Third-party package / image inputs | high | mitigate | No new runtime package dependencies; use verified immutable upstream provenance and checksums, record evidence, fail closed. |
</threat_model>
