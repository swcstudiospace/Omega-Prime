# Phase 120 Plan 01: Scaler core Summary

**Stdlib-only, event-sourced runner scaler with signed-webhook intake, one-shot delayed idle deadlines and a redacting CloudEvent publisher — 106 hermetic tests, 99% branch coverage on `omega_prime.ci_runners`.**

## Accomplishments
- `scaler.py`: `Scaler.handle(event) -> Step` folds JobEvent / LaunchSucceeded / LaunchFailed / RunnerExited / IdleDeadline / ControllerStarted. Launch count is `max(0, min(max, queued+busy) − (starting+idle+busy))`; reservations are released exactly once; agent 429 sets a capacity hold that clears on the next exit/completion; a rejected launch with a known registration emits a rollback `Reap(stop_agent=False)`; an ambiguous failure keeps the runner as IDLE. Restart reconcile reaps orphan processes and orphan idle registrations and keeps busy runners. Nothing happens before `ControllerStarted`.
- `jobs.py`: typed `WorkflowJob`, finite input/decision vocab, matching = labels ⊆ pool, private (explicit `true`) and allowlisted.
- `webhook.py`: streaming 1 MiB cap (Content-Length and chunked), HMAC-SHA256 via `compare_digest`, `workflow_job`/`ping` allowlist (others → 202 ignored), 4096 delivery LRU with separate `seen`/`commit`, shared ASGI helpers.
- `delayed.py`: `schedule(name, generation, delay_s, event) -> CancelHandle` / `cancel(name, generation)`; asyncio `call_later` adapter and injected Pulsar `deliver_after(payload, delay_s)` adapter. No timers, cron, polling or sleep loops.
- `publisher.py`: CloudEvents 1.0 with `omega.ci.runner.*` / `omega.ci.desktop.*` types; every adapter redacts (known secrets + shared patterns) and refuses non-JSON output or any surviving secret (for example as a dict key). JSONL file is created 0600 in a 0700 dir.
- `settings.py`: every canonical controller and agent variable from the plan, with defaults 8 / ceiling 10 / 180 s / 150 s; https-only desktop URL (no credentials, query or fragment); controller URL https (http only on loopback).
