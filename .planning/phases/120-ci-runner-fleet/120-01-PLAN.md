## Trust boundaries

| Boundary | Description |
|---|---|
| GitHub → webhook verifier | Untrusted raw bytes, headers, event names, and delivery IDs cross into the core. |
| Verified payload → typed job/scaler | Schema, repository identity, labels, ordering, and runner assignment affect capacity state. |
| Scaler decisions → controller ports | Decisions may lead to delayed destructive reap or event output with sensitive data; interpretation is outside the pure scaler. |
| Settings → core representations | Secret-file paths and injected transient values must not leak through repr or output. |

## STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation |
|---|---|---|---|---|---|
| T-120-01 | Spoofing | webhook signature verification | high | mitigate | Verify bounded raw body HMAC-SHA256 with constant-time compare before parsing or changing state. |
| T-120-02 | Denial of service | webhook body accumulation | high | mitigate | Enforce 1 MiB while receiving chunks and reject excess without unbounded buffering. |
| T-120-03 | Denial of service | delivery dedupe | medium | mitigate | Bound LRU to 4096; duplicate delivery cannot cause repeated mutation/effects. |
| T-120-04 | Tampering | webhook parsing and matching | high | mitigate | Allow only ping/workflow_job finite shapes; fail closed on public repos and require label subset. |
| T-120-05 | Tampering | job and idle-deadline state | high | mitigate | Enforce monotonic transitions and generation-match deadlines before reap. |
| T-120-06 | Denial of service | scaler reservations | high | mitigate | Reserve atomically within configured/hard caps and release matching reservation exactly once. |
| T-120-07 | Information disclosure | settings and event output | high | mitigate | Keep secret file references repr-safe; redact every event/log with known values and reject unsafe payloads. |
| T-120-08 | Denial of service | delayed event adapters | medium | mitigate | Use cancellable one-shot handles or injected deliverAfter capability; no recurring scheduling. |
| T-120-09 | Tampering | core dependencies and tests | medium | mitigate | Keep core stdlib/offline, with lazy optional EventStream and no network/framework test dependency. |
