## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Same-origin dashboard page to GET /api/session | The attach token crosses from the server into page JavaScript; it is the write-path credential for the terminal websocket and must never leak out of component memory. |
| Browser to /ws/tasks/{task_id}/terminal | The page sends the token and operator keystrokes over the socket built from location.host; a compromised or misrived url would hand the token and input to another origin. |
| Browser to /ws/events | Read-only event stream consumed by useDashboard; a malicious or malformed message must never corrupt Snapshot state or wedge the reconnect loop. |
| npm registry to build inputs | @xterm/xterm enters node_modules, the lockfile and the shipped bundle; a typo-squatted or floating version is supply-chain exposure. |
| Rebuilt static/cc artifact to every dashboard browser | The committed bundle is what users execute; accidental commits of build scratch or a bundle diverged from source are integrity breaks. |
