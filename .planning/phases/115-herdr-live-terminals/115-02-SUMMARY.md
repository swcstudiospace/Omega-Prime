# Phase 115-02 Summary

## Implemented

- `terminal_ws.py` (new) — `redact_ansi_frame` splits frames into escape/visible runs on the existing `_ANSI` pattern, keeps every escape run verbatim, and runs each visible run through the exact `sanitize_terminal_text` chain (Cc control-char drop except `\n`/`\t`, `redact_value`, then `_BEARER`/`_TOKEN`/`_JWT`/`_ASSIGN`), with the sanitizer's tail caps (200 lines, UTF-8-safe 64 KiB trim) applied only on the pathological path. `HerdrBridge` wraps an injectable async runner (default `terminal._read_pane`): `read_frame` issues exactly `["herdr","pane","read",pane,"--source","visible","--format","ansi"]` under `TERMINAL_READ_TIMEOUT_S` with the capture-size check and returns redacted text; `send_text`/`send_keys` issue exact `send-text`/`send-keys` argv and never log payloads. `poll_events` is an async generator driven by a sync pane provider: frames emit only when redacted content changes (a pane change always re-emits a first frame), statuses (`no_session`/`pane_closed`/`unavailable`) dedupe, `pane_closed` terminates, and `CancelledError` propagates. A 4-slot semaphore caps concurrency (`reserve`/`release`).
- `make_terminal_ws_endpoint(poller, bridge, *, token, readonly, auth_timeout_s, input_per_s, mono)` — auth-first protocol: `accept` then the first message must be `{type:"auth", token, mode:"rw"|"ro"}` within the timeout; non-string tokens, wrong tokens (`secrets.compare_digest`), wrong modes, and timeouts close 4401. Task ids validate exactly like the SSE route (query string, >256 bytes, control chars → 4404); rows are looked up across `active`/`idle_sessions`/`finished`; the bridge slot refusal closes 4429. The pane comes only from `terminal.resolve_task_pane` over the task row, re-resolved every poll cycle — client frames carry no pane ids and none are read from them. Writer/reader run as tasks with first-completion teardown; `input`/`keys` frames forward byte-exactly when the utf-8 payload is ≤ 4 KiB and the rolling 1 s / `input_per_s` window has room; read-only (server flag or client mode), oversized, over-rate, malformed, and paneless cases drop silently with no feedback or logging. The session always ends with an explicit close frame (a bare endpoint return completes the ASGI app without one, which would hang raw-ASGI peers), and teardown is cancellation-safe: the marked cancellation is saved and re-raised after cleanup so no unmarked re-delivery escapes the ASGI cancel scope (this was the source of a flaky portal teardown, fixed and stress-tested).
- `app.py` — `create_app` gains keyword-only `attach_token`, `terminal_readonly`, `terminal_bridge`, `terminal_auth_timeout_s`, `terminal_input_per_s` (poller stays positional); the token is minted once per app with `secrets.token_urlsafe(32)` (or the injected test value) and lives only in `create_app` locals. `GET /api/session` returns `{token, readonly}` with `Cache-Control: no-store`, 403 when `sec-fetch-site` is present and not `same-origin`/`none`. `WebSocketRoute("/ws/tasks/{task_id:path}/terminal", …)` mirrors the SSE route's `:path` converter so ids containing `/` (e.g. `worker%2F1`) route correctly. `_DashboardGuards` now admits websocket scopes only for `/ws/` paths with an allowed loopback Host and an explicit allowed Origin (case-insensitive `http://127.0.0.1:PORT` / `http://localhost:PORT`), closing 4403 before any application logic; HTTP stays GET-only byte-identical; per-instance CSP copies gain `connect-src 'self' ws://127.0.0.1:{port} ws://localhost:{port}` while `default-src 'self'` / `font-src 'self'` substrings hold.
- `__main__.py` — serve path accepts `--terminal-readonly` (default off) and threads `terminal_readonly=args.terminal_readonly` into `create_app`; `next-id`/`assign-id`/`assign-ids`, `--once`, `--stop`, and the pidfile lifecycle are untouched.
