<pitfalls>
## Pitfalls for the execution planner

- Do NOT touch `omega_prime/engine/sandbox.py`'s bwrap path or `wrap()`; the backend branches at selection time (before `sandbox_ready`/`wrap` in `_run` and in `probe`) — bwrap behaviour must be byte-identical when the env is unset.
- Do NOT re-implement model routing in the backend: it consumes `plan_router.select`'s `Choice` (allowlist, quota, fallback, `fallback_from`) and passes plan/model into `run_gsd_stage`; omp-sandbox's `stageRoute` must agree (zai primary ⇒ no fallback ⇒ engine `fallback_from=None`).
- The Anda wrapper emits unsolicited event lines interleaved with replies, every object carries `"attestation":"mock"`, and `down` is asynchronous (reply lands before exit): the client must match replies by `id`, ignore/handle unknown events, and drain on shutdown. Missing wrapper binary or non-zero exit ⇒ `SandboxUnavailable`, never a silent bwrap fallback (uplift `<GRACEFUL_DEGRADATION>`).
- `run_gsd_stage` returns immediately (`{stageId, …}`); completion arrives as the `stage_done` event and the record comes from `sandbox_status` — poll both, with the engine's no-time-cap rules (no invented deadline; liveness via the wrapper's event stream, explicit abort via the `abort` tool).
- One stage at a time per workdir (core.ts:233-235): plan→execute must be sequential on one job (that is exactly W112-05's ordering test).
- `export_commits` requires `seed_repo` at `up` time (`no seeded repo` otherwise); the engine's `up` args must therefore use `seed_repo` (bundle seed from the job worktree) rather than `workspace_host_path` when exports are wanted — or mount the worktree and accept `bundle: null`; pick ONE shape and pin it in tests (112-02 decides: seed_repo from the allowlisted worktree, per n3 step 3 + step 4).
- Never widen `EngineResult`, never write a second redactor or block writer, never print `OMEGA_PRIME_OMP_ALLOW_ZAI`/`ZAI_API_KEY` values; presence/truthiness only.
- omp-sandbox tests must keep the `OMP_SANDBOX_STATE` tmp-override + dynamic-import discipline (config.ts captures env at module load — guards.test.ts:17-22 comment) and must not touch the live 00025 containers or any real podman socket (they cannot here; keep it that way).
- `npm ci` in this tree needs `--ignore-scripts` (better-sqlite3 native build fails without node-gyp headers); tsc and node --test need declarations only.
</pitfalls>
