<assumption_delta_decision>
- Decision: the client is a thread+queue reader over Popen pipes (mirroring OmpSession's shape) rather than select polling — replies must be matched by id while unsolicited event lines interleave (client.rs:129-158), and a blocking readline thread is the boring stdlib way to keep both orders correct.
- Decision: keyword name engine_plan on both attach entry points instead of the contract's literal `plan` — forced by ultrathink_engine's existing `plan: Mapping` positional (a duplicate parameter name is a SyntaxError); engine_plan is the established in-tree name for the requested model plan (attach.py:174, audit C3), it keeps the two entry points symmetric, and 112-03 pins the same name.
- Decision: backend selection wins over the unsandboxed override — OMEGA_PRIME_OMP_BACKEND=omp-sandbox is an explicit operator choice of a *different* sandbox, and UNSANDBOXED is the bwrap path's escape hatch; conflating them would let one knob silently disable the other.
- Decision: up seeds with seed_repo (git bundle from the allowlisted worktree) rather than mounting workspace_host_path, because export_commits refuses without a seeded repo (core.ts:192) and results coming back is a phase requirement (C7); the worktree is still allowlist-checked engine-side and re-validated by the core.
- Decision: the wrapper child env is child_env(env) plus every OMP_SANDBOX_* key from the engine env (child_env copies only named keys — jobs.py:192-217 — so the core's own knobs would otherwise be dropped) with PATH preserved; this is how the engine-side allowlist value reaches the TS core's allowedDir for its independent re-check.
- Decision: bounded waits only for the wrapper_ready handshake and individual tool replies (constants local to sandbox_omp, sized like _READY_TIMEOUT/_COMMAND_TIMEOUT); the stage wait itself has no deadline — events stream, interrupt aborts explicitly, EOF or non-zero exit is a SandboxUnavailable (never a hang, never a silent fallback).
- No add-alongside debt: exactly three engine files, no new module beyond sandbox_omp.py, no tests (112-03 owns them), no dashboard changes, no omp-sandbox changes.
</assumption_delta_decision>
