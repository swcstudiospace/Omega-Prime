# Phase 98-04 — Composition, user surfaces, and integration

## Objective

Complete production composition, user-facing command and doctor behavior, operational documentation, and fake-backed end-to-end validation after both wave-2 plans land.

## Context

Wave 3 depends on completed `98-02` and `98-03`; no work starts until both land and their shared contract/tests agree. `tools/lead.py` doctor reporting is edited serially here, after 98-02 lead memory work. Shared APIs/result shapes and ownership are frozen in `PLAN.md`, which is authoritative. Consume phase-97 resolver and typed substrate outcomes; no phase-98 transport repair or guessed substrate contract. All work uses loopback fakes; no live service, deployment, or credential/config-value inspection.

## Scope and must-haves

- `omega_prime/mcp_server.py`: construct and inject exactly one coordinator after resolving the authoritative raw SubstrateClient and optional Hindsight backend. Never inject `_DeskSubstrate` as the memory client, construct separate coordinators, or restore implicit localhost as configured source. Compose one MemoryStore, raw resolved substrate client, optional HindsightService, and shared validated scope/repo policy.
- `omega_prime/commands/__init__.py`: route `/omega-recall` through lead recall and `/omega-retain` through approval-gated lead retain, never builtin memory or a bank-prefix workaround. Preserve secret-before-dispatch and grant/evidence requirements. Propagate structured results, source/backend names, states and sanitized diagnostics. Fail on `ok:false`, top-level error, or failed required write; local save alone is not overall success. Keep one result representation.
- `omega_prime/tools/lead.py`: serially add doctor lines for local, substrate, Hindsight. Recall/doctor always report all three names and exactly `answered`, `empty`, `not_configured`, `unreachable`, or `unauthorized`. Retain reports participation separately (`selected_for_write`, `attempted`); intentionally unselected configured Hindsight is neither `not_configured` nor an attempted write destination. Doctor remains read-only. Preserve explicit brief invalidation/refresh after retain.
- `omega_prime/substrate/probes.py`: touch only if needed to surface phase-97 authoritative config rather than duplicate env-only/localhost resolution. Preserve unset-Hindsight/no-secret-read/no-network behavior; no new transport probe, write, or selector configuration.
- Correct assigned docs (`docs/substrate.md`, `omega_prime/grokbot/SETUP.md`, `omega_prime/skills/hindsight-memory/SKILL.md`) to match selector/default/recall-vs-write behavior, states, fallback policy, bounds, secret source and repo isolation. Remove bridge/service-first fallback claims and unverified Hindsight document-ID guarantees. Distinguish local profile CRUD from shared retention; add no hard-coded live URL.
- Integration tests use loopback fakes/scripted transports and actual production registry, command, and doctor paths. No live network, deployment, credentials, or config-value inspection.
