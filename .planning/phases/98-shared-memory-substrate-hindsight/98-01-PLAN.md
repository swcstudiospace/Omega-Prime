# Phase 98 Plan 01: backend contracts and secure Hindsight service

## Objective

Deliver the complete, usable backend-resolution primitives and harden the optional Hindsight HTTP service before recall and retain integrations are implemented. This plan does not implement recall merging, retain coordination, production registry composition, commands, or doctor reporting.

## Context

Execution is blocked until phase 97 has been merged/rebased into this worktree and its actual public APIs have been re-read. Confirm the authoritative effective substrate URL/configuration resolver, memory search's structured empty/error result, memory write's `expected_version` and idempotency argument semantics, and typed auth/unreachable classifications. The current checkout at 44b28df does not contain those contracts. Do not guess `expected_version`, reinterpret `None`, inspect a transport/private client, or treat `memory_search() == []` as healthy. If any prerequisite is absent or ambiguous, stop before editing runtime files and record the exact missing contract.

The frozen shared design for this phase is:

- `omega_prime/memory/backends.py` exposes `resolve_memory_backends(...) -> MemoryBackends`, plus backend/result types, validation/canonicalization helpers, trusted default scope/repo, selected backend, and safe configuration states. Exact resolver argument names adapt only to phase-97 public contracts; do not create a parallel settings convention.
- Backend names are `local`, `substrate`, and `hindsight`; selector values are exactly those three. The default is substrate only when the phase-97 resolver explicitly returns a configured URL; otherwise local. Invalid selector/configuration is a validation error, not a fallback.
- Backend states are exactly `answered`, `empty`, `not_configured`, `unreachable`, `unauthorized`. Errors/diagnostics are structured and sanitized separately from state. Do not derive authorization or outage from exception strings.
- Shared content canonicalization for hashing is UTF-8 SHA-256 of outer-whitespace-stripped content after CRLF/CR becomes LF; no case folding or fuzzy matching. `decode_local_record(stored_text, expected_bank)` consumes the complete stored string and validates/strips only its exact known outer bank envelope internally; search and hash only the decoded content.
- Wave 1 owns `encode_local_record(record) -> str` and `decode_local_record(stored_text, expected_bank) -> LocalRecord|LegacyRecord` in `backends.py`. Encoding returns the complete persisted string with exactly one `[hindsight:<bank>]` outer wrapper, followed by `[omega-memory:v1]` and compact JSON using `ensure_ascii=False, sort_keys=True, separators=(",", ":")`; pass that complete string directly to `MemoryStore.add("memory", encoded)`, never to `Hindsight.retain` (which would add a second bank envelope). Decoding consumes the complete stored value, validates and strips exactly the expected outer bank wrapper internally, then parses the version marker/JSON and verifies inner bank equality. Other-bank records are ineligible, not malformed. Expected-bank-wrapped legacy records without the version marker remain readable as plain unscoped content. Recognized malformed/unknown-version records fail rather than degrading to legacy. Search and hash decoded content only, never serialized metadata. The exact JSON schema is `v=1`, `bank`, `scope`, `repo` (string|null), `kind`, `content`, `source` (string|null), `receipt_path` (string|null), `tags` (list[str]), `graph_id` (string|null), `task_id` (string|null). Reject `ENTRY_DELIMITER` before encoding; full wrapper/JSON plus existing separators counts against the existing 2200-character memory budget, with no increase.
- Wave 1 defines the `MemoryBackends` operation-ledger container, but wave 2/98-03 behavior follows the frozen contract in `PLAN.md`: generated UUID binding before local mutation; canonical typed fingerprint; reject mismatches and unknown/evicted caller IDs before I/O; LRU of 1024 completed entries, in-flight never evicted; no TTL/time/session cap, durable journal, or retry loop. The API carries explicit `graph_id=None, task_id=None` keywords after `tags=None`.
- Network timeouts use only ordinary existing per-request HTTP timeouts and map to sanitized `unreachable`; they are never session/turn/execution budgets. Fake timeout tests must prove recall keeps other hits and retain reports local success plus overall failure while continuing to other required destinations. Do not add any session, turn, execution-budget, or wall-clock cap.
- Scope/repo are trusted, validated before I/O, and required to maintain repository isolation across every backend. Legacy local banks remain readable only in the explicitly unscoped policy; records without repo provenance are never presumed repo-scoped.
- No phase-98 transport repair is allowed. No Hindsight URL is hard-coded or inferred from localhost. Hindsight is optional and is not constructed when its URL is absent.
