<domain>
## Phase boundary

The user's operating model: push this repository to GitHub, ask the default Grok Bot to set it up, and get an "Omega Prime" Bot whose slash commands and prompting reach the Omega Prime core's skills and tools. Today that path does not exist. The template (`omega_prime/grokbot/templates/OMEGA_PRIME.md`) is a pointer file. `omega_prime/grokbot/manifest.py` emits JSON "for direct import into Grok Bot settings", but no such settings import field is documented. The repository root has no `.cursor-plugin/`, `mcp.json`, `.mcp.json` or `.grok/config.toml`.

This phase packages the existing core so that import works. It wraps the core and does not rewrite it.
</domain>

## Locked decisions (user, 2026-10-12)

- **D-01 Scope:** A new import-packaging phase sits before marketing. It was inserted as decimal Phase 77.1, so no roadmap renumbering. Phase 78 marketing now depends on 77.1.
- **D-02 Host placement — both entries:** The default MCP entry is a stdio `command` that the Bot runs on its own cloud computer: bootstrap (clone, venv, pinned install), then the existing MCP host over stdio. The documented alternative is a public HTTPS host the operator runs (the existing SSE/Streamable HTTP transports with bearer auth). A local verifier checks that both entries resolve. The Bot cannot reach `localhost` on the operator's machine.
- **D-03 Slash commands:** Generate one `/omega-<name>` command per checked-in skill (`omega_prime/skills/*/SKILL.md`, 27 today) and per routine (`omega_prime/routines/*.md`, 7 today) from those files, so the set cannot drift. They execute through the existing `omega_command` tool and command catalog (`omega_prime/commands/`). The 12 curated commands stay. Generated entries must be deterministic, and a check mode must fail on drift.
- **D-04 TypeScript:** Python core only. T3MP3ST (`redteam/`) stays an optional, operator-started, default-off backend. It is not declared as a second MCP server.
- **D-05 Sequencing:** Phase 77 UAT completes first. Planning for this phase follows Phase 77 acceptance.
- **D-06 Import path:** Bot-driven setup is primary. The user asks the default Grok Bot to set Omega Prime up from the GitHub URL; the Bot clones the repo into its `/workspace`, runs the bootstrap, and adds Omega Prime as a custom Command (stdio) MCP server on its own computer. The Cursor plugin manifest (`.cursor-plugin/marketplace.json`, `.cursor-plugin/plugin.json`, root `mcp.json`) is still generated as the secondary route for Cursor Teams/Enterprise team marketplaces.
- **D-07 Skill files:** Fix all 7 non-conformant skills. Repair the YAML in desk-bootstrap, desk-doctor, desk-gateway and hindsight-memory. Add frontmatter to lead-pack. Set `name` to the folder name for `security-secrets-handling` (was `secrets-handling`) and `security-supply-chain` (was `supply-chain`), and update every reference in the same change.
- **D-08 Slash surface:** `/omega-<name>` commands work by routing through the existing `omega-commands` skill and the `omega_command` tool in any host. Generated plugin command files add native palette entries where supported. No wrapper skills.
- **D-09 First start:** The stdio entry auto-bootstraps once, under a lock and a completion stamp, when the environment is missing: pinned install, with progress on stderr only and stdout reserved for protocol. Then it serves. The documented setup prompt also bootstraps ahead of time, so later starts are fast. An interrupted first start must resume safely on the next start.

## Resolved from the user's earlier answers (no re-ask)

- Skill commands load the skill's instructions; routine commands run the routine through the existing workflow runner where one exists, and otherwise load its instructions (D-03 wording).
- Collision rule: curated names win; a generated name that collides takes a `-skill` or `-routine` suffix; any collision left after that fails generation. Known suffixed results: `/omega-python-skill`, `/omega-onboard-routine`, `/omega-connectors-routine`, `/omega-ultrathink-skill`, `/omega-ultrathink-routine`. The `omega-` prefix is not doubled (`omega-commands` → `/omega-commands`).
- The HTTPS alternative ships as docs plus a non-secret example config; the local verifier checks that it resolves (D-02).
- The 12 curated commands also get generated command files.
