## Warnings

### WR-09: Cold-install operator paragraph omits exit 12

**File:** `docs/grok-bot-native.md:105`
**Issue:** The new paragraph says "A failed install exits 10 or 11 with one JSON class line on stderr." But `--bootstrap-only` runs `python -m omega_prime.tooling.plugin --check` on every bootstrap, and the exit table four dozen lines below (lines 154–155) maps a failed `--check` to exit 12 — plain 12 for drift `--write` repairs, 12 with `"detail":"content_invalid"` for source errors `--write` cannot repair. A fresh clone whose generated outputs are stale (exactly the drift case the cold observation is meant to surface) therefore fails the documented observation with exit 12, contradicting the runbook sentence an operator follows.
**Fix:**
```markdown
A failed install exits 10, 11 or 12 with one JSON class line on
stderr (10 missing prerequisite, 11 install or plugin-check crash
`"step":"plugin_check"`, 12 catalog drift or `content_invalid`).
```
