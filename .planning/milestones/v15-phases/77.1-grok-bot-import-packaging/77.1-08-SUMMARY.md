## Deviations from Plan

Writer-reported (`Write77108`):

1. **Overlay is every tracked file.** The overlay copies every `git ls-files` entry, a superset of the A-M6 root plugin set and close to a fresh clone. Untracked files are excluded, so new generator output must be `git add`ed before it counts.
2. **Warm venv by path entries instead of an install.** The venv is a fresh `--without-pip` venv. Its single `omega_prime_fresh_clone.pth` lists the overlay root, then the running interpreter's purelib and platlib. The real `.venv` is never written and its editable finder is not loaded. Because of this, the test must run with the `.venv` interpreter at the same minor version, and otherwise fails with "run with .venv/bin/python".
3. **Private interpreter shim.** A `python3.12` shim to `realpath(sys._base_executable)` is first on `PATH`, so the launcher's `BASE_PY` matches the stamp. The fixture also requires `bash`, `git` and `flock`, and a base interpreter that can import `venv` and `ensurepip`.
4. **Stamp `commit=none`.** Gitlinks become empty dirs and there is no `.git`, so the overlay never fetches submodules. The real-clone LOCAL-PROOF covers the pinned-submodule path.
5. **LOCAL-PROOF pointer placement.** The pointer is the module docstring, not a separate comment. It only names checks and claims nothing of its own.
6. **Cold case behaviour.** The cold case passes proxy, pip-index and CA variables through from the environment and waits up to 3600 s. On early stdout close it asserts exit 10 or 11 with a matching class line, then fails as "cold bootstrap did not complete".
7. **No verification by the writer.** The writer did not run, lint or format the file, and made no commit. All checks above were run by the parent.

**Impact on plan:** No scope creep. The only file is the owned test file.
