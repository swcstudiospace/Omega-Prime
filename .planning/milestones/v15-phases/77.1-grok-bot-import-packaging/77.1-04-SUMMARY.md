## Deviations from Plan

Writer-reported (`Write77104`):

1. **Shared provenance filter.** `lint_template` imports `checked_in_skills(root)` / `checked_in_routines(root)` from `omega_prime.commands.generated` instead of `local_validation._tracked_files`. The plan says to share the generator's provenance filter, not reimplement it. The contract agreed with the 77.1-01 writer: pure enumeration that never raises, `()` when the folders are absent, and no `omega_prime.grokbot` import from `generated.py`, which would create a cycle. This creates an import dependency on 77.1-01's `generated.py`; both are in wave 1.
2. **`mcp` endpoint.** The SSE endpoints dict gained `mcp: <base>/mcp`. This makes the added Streamable HTTP transport concrete: `remote.py` always mounts `streamable.route` next to `/sse`, and only this plan's tests pinned the exact endpoints dict.
3. **Root-relative command.** `STDIO_COMMAND` is a root-relative constant, not an absolute path computed per root. The plan allows either; the constant keeps the manifest digest machine-independent.
4. **Alias kept.** The `generate_grokbot_manifest = generate_manifest` alias stays because `sync.py`, which this plan does not own, imports it.

**Impact on plan:** No scope creep. All deviations stay inside the plan's must_haves.
