**CLI and drift contract, `catalog.py:167-191`.** Generalize from one file to a `{relative_path: text}` mapping, and add orphan detection for `omega_prime/grokbot/plugin/commands/*.md`:

```python
def main(argv: list[str] | None = None) -> int:
    """Render or check the catalog. Exit 0 on success."""
    parser = argparse.ArgumentParser(prog="omega-prime-tool-catalog")
    parser.add_argument("--root", type=Path, default=None)
    parser.add_argument("--out", type=Path, default=None)
    parser.add_argument("--check", action="store_true")
    args = parser.parse_args(argv)
    root = (args.root or Path(__file__).resolve().parents[2]).resolve()
    out = args.out or (root / "docs" / "tool-catalog.md")
    with tempfile.TemporaryDirectory(prefix="omega-prime-catalog-") as tmp:
        fresh = render(root, Path(tmp))
    if args.check:
        try:
            current = out.read_text(encoding="utf-8")
        except OSError as exc:
            print(f"catalog --check: cannot read {out}: {exc}", file=sys.stderr)
            return 1
        if current != fresh:
            print(f"catalog --check: {out} is stale; rerun with --out", file=sys.stderr)
            return 1
        print(f"catalog --check: {out} up to date")
        return 0
    out.write_text(fresh, encoding="utf-8")
    print(f"catalog wrote {out}")
    return 0
```

Rules to keep:
- `render(root) -> dict[str, str]` is pure and deterministic. It does not import `mcp_server`. Unlike `catalog.py`, the plugin render needs no registry, so `--check` stays cheap enough for the bootstrap.
- Generation errors (invalid name, collision, bad frontmatter) raise with the source path, the same way `catalog.py:145-151` raises `SystemExit(f"tool catalog: roster names {name!r} …")`. Nothing is ever dropped.
- `--check` messages go to stderr and exit 1. Success goes to stdout and exits 0. On a generation error, nothing is written (`test_tool_catalog.py:37-61` proves this for the catalog: output bytes, mode, mtime and inode unchanged).
- Writes: `manifest.py:404` uses `atomic_write_text(args.out, data + "\n", mode=0o644)`. Committed generated files must be written with `mode=0o644`, because `fs.atomic_write_text` (fs.py:35-41) defaults to `PRIVATE_FILE_MODE = 0o600`.
- Version and repository come from `pyproject.toml` via stdlib `tomllib` (py ≥ 3.11, `pyproject.toml:8`): `version = "0.1.0"` (3), `Repository = "https://github.com/swcstudiospace/omes-bot"` (42). The plugin `name` is `omega-prime` (RESEARCH layout). It is not the repository name.
- Content contracts: RESEARCH §Recommended layout, §Stdio default entry, §HTTPS alternative entry, §Generation rule (applied table, 46 entries), §Drift `--check` (every failure class), and P-9/P-15 (relative paths, no `..`, kebab names, `name`+`description` frontmatter).

**Source:** `oneclick._hold_launch_lock` (110-175). It uses a sidecar `<base>.lock` and fails open when the lock is foreign-owned. **Apply to:** bootstrap `flock` semantics.
