# Phase 85 — XML prompt standard and gate (Plan 01)

Requirements: PROM-01, PROM-02.

1. `omega_prime/tooling/prompt_format.py`: `check(root) -> list[str]` +
   `--check` CLI (exit 1 with problems, 0 clean), following
   `tooling/catalog.py`/`plugin.py` conventions. Checks: seat prompt and
   core directives parse as strict XML with roots `agent`/`core_directives`;
   assembled prompt parses as a two-root fragment (`core_directives`,
   `agent`) with no unfilled `{{...}}`; skill/routine/command envelopes;
   runtime builder probes. Exclusions (vendored pack, Grok template, eval
   data, tool descriptions) documented in the module docstring.
2. `omega_prime/tests/test_prompt_format.py`: repo-clean assertion +
   tmp_path negative tests (unwrapped skill, unclosed routine).
3. Seat prompt gains a `<prompt_format version="1">` section; assembled
   prompt regenerated (`assemble-prompts.sh`), `--check` clean.
4. CI `docs` job gains `python3 -m omega_prime.tooling.prompt_format --check`.
